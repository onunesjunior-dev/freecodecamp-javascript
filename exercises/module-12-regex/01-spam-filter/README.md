# Spam Filter

Workshop do Módulo 12 (Expressões Regulares) — 32 passos. Motor heurístico
anti-spam com 5 regex de deny-list (pedidos de socorro, valores em dólares,
ofuscação leetspeak de "free money" e "stock alert", saudação de golpe
nigeriano). Só o `script.js` consta no bloco consolidado do caderno.
